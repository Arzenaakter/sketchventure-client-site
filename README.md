## ✨ Overview

**SketchVenture** is a full-stack web application designed for a **Summer Camp School**, where students can discover and enroll in exciting extra-curricular activities with a smooth and secure experience.


---

## 🚀 Features

### 🌐 Public Section
- Responsive Home Page 📱
- Hero Slider & Engaging UI
- Popular Classes & Instructors
- Upcoming Classes Showcase

### 🔐 Authentication
- Firebase Login / Register
- JWT Secure Authorization
- Private Routes Protection

### 📊 Role-Based Dashboard

#### 👨‍💼 Admin
- Manage users & roles
- Approve / reject classes
- Full system control

#### 👩‍🏫 Instructor
- Add new classes
- Manage personal classes

#### 🎓 Student
- Select classes
- Remove selections
- Secure enrollment via Stripe 💳
- Payment history tracking

---

## 💳 Payment System
- Integrated **Stripe Payment Gateway**
- Smooth checkout experience
- Secure transactions 🔒
